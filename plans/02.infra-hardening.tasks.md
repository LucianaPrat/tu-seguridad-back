## Deviations from plan
- **T02**: plan said `npm ci --omit=dev` then `npm run build`, but the TS build needs devDeps (nest-cli/tsc). Workflow does a full `npm ci`, builds, then `npm prune --omit=dev` to slim the runtime. Added secrets `PROD_APP_DIR` and var `PROD_APP_PORT` (not in the plan's secret list) — the host path and health-check port have to come from somewhere.
- **T03**: breaker state exposed via a service-level `circuitState` getter instead of `CameraStatusRegistry`, because the breaker is global (one upstream) while the registry is per-camera — folding it in would misrepresent it. Plan explicitly allowed this fallback.
- **T04**: `/metrics` also appears in `openapi.json` (Swagger scans the controller); harmless and matches live `/docs-json`. Route is VERSION_NEUTRAL to land at bare `/metrics`.
- **T06a**: no real `secrets.enc.yaml` or `.sops.yaml` committed — creating them needs the production age key, which isn't available in this environment. Full procedure documented for the owner instead.
