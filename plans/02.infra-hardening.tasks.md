## Deviations from plan
- **T02**: plan said `npm ci --omit=dev` then `npm run build`, but the TS build needs devDeps (nest-cli/tsc). Workflow does a full `npm ci`, builds, then `npm prune --omit=dev` to slim the runtime. Added secrets `PROD_APP_DIR` and var `PROD_APP_PORT` (not in the plan's secret list) — the host path and health-check port have to come from somewhere.
- **T03**: breaker state exposed via a service-level `circuitState` getter instead of `CameraStatusRegistry`, because the breaker is global (one upstream) while the registry is per-camera — folding it in would misrepresent it. Plan explicitly allowed this fallback.
- **T04**: `/metrics` also appears in `openapi.json` (Swagger scans the controller); harmless and matches live `/docs-json`. Route is VERSION_NEUTRAL to land at bare `/metrics`.
- **T04 (port)**: three things the plan did not ask for, all forced by what `develop` looks like now. The poll metrics carry a `cameraId` label — eight cameras, 24 series, and a slow recorder or a dead channel has to be visible on its own. The `pollOnce` the original commit instrumented no longer exists, so the outcomes were re-derived against today's exit paths: capture failure and detection failure count `error`, a failed live-frame write still counts `success` (the poll detected; the thumbnail is recorded on the camera's status), an unexpected throw counts `error`, and an in-flight skip is counted but **not** timed — a skip did no work, and a zero in the histogram would drag the percentiles of the polls that did. The WebSocket gauge increments after the `spaceId` check `develop` added, not after the token `catch` where the commit put it: there it would have counted sockets the gateway then rejects. Finally, `test/utils/bootstrap-e2e-app.ts` clears `prom-client`'s default registry before booting, because registering the same metric twice throws and the e2e harness boots the app per spec file.
- **T04 (still open)**: nothing scrapes `/metrics` yet. The collector in `ops/otel-collector/` carries a traces pipeline only; a `prometheus` receiver pointed at this endpoint, and the Grafana dashboards over it, are separate work.
- **T06a**: no real `secrets.enc.yaml` or `.sops.yaml` committed — creating them needs the production age key, which isn't available in this environment. Full procedure documented for the owner instead.
