## Deviations from plan

- **T01**: the plan floated a 413 with its own `PAYLOAD_TOO_LARGE` code. It answers `400 VALIDATION_ERROR` instead — the same thing the in-service size check already answers and the same thing `@ApiFailures` already documents — so `openapi.json` did not move and a caller cannot tell where the limit was enforced.
- **T02**: the plan said a suite needing the limiter off would "override the guard". It cannot: `MetricsThrottlerGuard` is registered under `APP_GUARD` alongside the three authentication guards, so overriding it by class replaces nothing and overriding the token would take authentication with it. `bootstrapE2eApp` overrides `ThrottlerStorage` with a counter that always reports zero hits instead — the real guard stays in the chain.
- **T02**: `bootstrapE2eApp` also gained `metrics` in its `setGlobalPrefix` exclude list, which `main.ts` already had. One word, and the throttling spec needs `/metrics` to be where production serves it. The full `configureApp` extraction that removes this class of drift is still T11's.
