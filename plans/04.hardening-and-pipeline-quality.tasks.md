## Deviations from plan

- **T01**: the plan floated a 413 with its own `PAYLOAD_TOO_LARGE` code. It answers `400 VALIDATION_ERROR` instead — the same thing the in-service size check already answers and the same thing `@ApiFailures` already documents — so `openapi.json` did not move and a caller cannot tell where the limit was enforced.
- **T02**: the plan said a suite needing the limiter off would "override the guard". It cannot: `MetricsThrottlerGuard` is registered under `APP_GUARD` alongside the three authentication guards, so overriding it by class replaces nothing and overriding the token would take authentication with it. `bootstrapE2eApp` overrides `ThrottlerStorage` with a counter that always reports zero hits instead — the real guard stays in the chain.
- **T05**: no `ScheduleModule.forRoot()` in `RetentionModule` — `PipelineModule` already calls it, and the explorer it installs discovers `@Cron` on every provider in the application. A second `forRoot()` registers the explorer, and every job with it, twice.
- **T05**: the snapshot sweep carries no "still referenced by an event inside the window" clause the plan described. Events and their frames age together, so a frame past the window is only ever pointed at by an event past it too — the clause would have been a join that can never change the answer.
- **T04**: the plan (and `AUDIT_BACKLOG` #70) said unit coverage was 77.2% and had to be raised past the 80 threshold first. It measures **85.55% lines** today — the figure was stale, so no coverage work was needed and the step was simply wired up. The plan's instruction not to lower the threshold to meet the number did not come up.
- **T03**: the plan said "call `compareWithDummy` before returning" on every not-found branch, recovery included. That works for login and does nothing for the recovery request routes — what an existing address pays there is a database write and a relay round trip, not a hash, and no cheap dummy imitates them. Those two routes answer first and issue the credential detached instead. The invitation-accept lookup was left alone: it resolves a hashed token, and both outcomes cost one SHA-256 and one indexed read.
- **T02**: `bootstrapE2eApp` also gained `metrics` in its `setGlobalPrefix` exclude list, which `main.ts` already had. One word, and the throttling spec needs `/metrics` to be where production serves it. The full `configureApp` extraction that removes this class of drift is still T11's.
